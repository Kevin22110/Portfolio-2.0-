# 🚀 Meu Portfólio Pessoal

Bem-vindo ao repositório do meu portfólio! Este projeto foi desenvolvido para centralizar meus trabalhos e demonstrar minhas habilidades técnicas em desenvolvimento front-end.

## ✨ Sobre o Projeto
O foco principal deste portfólio é o **minimalismo** e a **performance**. Busquei criar uma interface limpa, onde o conteúdo é o protagonista, utilizando animações de scroll para tornar a navegação mais fluida e moderna.

## 🛠 Tecnologias Utilizadas
* **HTML5:** Estrutura semântica para melhor acessibilidade e SEO.
* **CSS3:** Estilização avançada com foco em layouts responsivos e animações personalizadas.
* **JavaScript (ES6+):** Lógica de interatividade, manipulação do DOM e consumo de dados dinâmicos.

## 📂 Projetos em Destaque
Dentro do portfólio, você encontrará demonstrações de:
* **Aplicação de Previsão do Tempo:** Integração com API em tempo real para exibição de dados climáticos. ( a api não esta funcionando no momneto)
* **Animações de Scroll:** Implementação de efeitos visuais suaves durante a rolagem da página.
